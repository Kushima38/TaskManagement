# 要件定義書

## 1. 目的・背景

スクール（RaiseTech）の課題として、Trello風のタスク管理アプリを作る。
作る過程を通して、Webアプリ開発の技術を身につけることを目的とする。

## 2. 想定ユーザー・利用場面

| 項目 | 内容 |
|---|---|
| 想定ユーザー | 個人（1人で使う） |
| 利用場面 | 自分のタスク（学習や課題など）を管理する |
| ログイン | なし |

## 3. 機能要件

### 3.1 アプリの構成

| 要素 | 内容 |
|---|---|
| ボード | 1つだけ |
| リスト（列） | `やること` → `着手` → `完了` の3つで固定（追加・削除・名前変更はできない） |
| カード | 1つ1つのタスク。ユーザーが作成・編集・削除・移動する |

### 3.2 カードの項目

| 項目 | 必須 | ルール |
|---|---|---|
| タイトル | 必須 | 1〜50文字。前後の空白は取り除いてから保存・チェックする（空白だけのタイトルは不可） |
| 説明 | 任意 | 複数行可、1000文字まで |
| 期限 | 任意 | 日付のみ（時刻なし）。今日以降の日付のみ（下の「期限の入力ルール」を参照） |
| 優先度 | 必須 | `高` `中` `低` の3段階。初期値は `中` |
| ステータス | 必須 | `やること` `着手` `完了` のいずれか。作成時は「カード追加ボタンを押した列」が入る |

**文字数の数え方**：見た目の1文字を1文字として数える（全角・半角・絵文字のどれも1文字、改行も1文字）。

**期限の入力ルール**

| 場面 | 今日より前の日付 |
|---|---|
| カードの作成 | 入力できない |
| 編集で期限を変更したとき | 入力できない |
| 編集で期限を変更していないとき | そのまま保存できる（期限切れのカードでも、他の項目を編集できるようにするため） |
| 期限を消す（期限なしにする） | いつでもできる |

**「今日」の基準**：日本時間（JST）の日付とする。期限のチェックとF8の表示の両方に使う。

### 3.3 機能一覧

| # | 機能（ユーザーは〜できる） |
|---|---|
| F1 | ボード上で3つの列と、各列のカードを一覧で見られる |
| F2 | どの列からでもカードを作成できる |
| F3 | カードの内容（タイトル・説明・期限・優先度）を編集できる |
| F4 | カードを削除できる |
| F5 | カードを別の列に移動できる（詳細・編集画面のプルダウンで） |
| F6 | ドラッグ&ドロップでカードを別の列に移動できる |
| F7 | ドラッグ&ドロップで列の中のカードの並び順を変えられる |
| F8 | 期限切れ・今日が期限の未完了カードが目立って表示される |
| F9 | 列ごとの「並べ替え」ボタンで、カードを自動で並べ直せる（並べ直した順番が保存される） |
| F10 | 優先度をラベルの文字と色で見分けられる |

### 3.4 並べ替えのルール（F9）

| ボタン | 並び順 | 同じ値のとき |
|---|---|---|
| 期限順 | 期限が近い順。期限なしのカードは一番下 | 優先度が高い順 |
| 優先度順 | `高` → `中` → `低` | 期限が近い順 |

期限も優先度も同じカードは、並べ替える前の順番を保つ。

並べ替えボタンを押すと、その結果が手動の並び順として保存される。そのあとはドラッグ&ドロップで自由に並べ替えられる。

### 3.5 表示のルール（F8・F10）

| 対象 | 条件 | 表示 |
|---|---|---|
| カードの表示項目 | 常に | ボード上のカードには、タイトル・優先度ラベル・期限（あれば）を表示する。説明はS3で見る |
| 優先度 | 常に | カードに `高` `中` `低` のラベルを表示（高＝赤、中＝黄、低＝灰） |
| 期限切れ | 期限が今日より前、かつステータスが `完了` 以外 | カードの背景を薄い赤、枠を赤にする |
| 今日が期限 | 期限が今日、かつステータスが `完了` 以外 | カードの背景を薄いオレンジ、枠をオレンジにする |
| 空の列 | 列にカードが0枚 | 列の中に「カードはありません」と表示する（カードをドロップできる領域は残す） |

### 3.6 カードの置き場所のルール

| 操作 | カードが入る位置 |
|---|---|
| カードの作成（F2） | 作成した列の末尾 |
| プルダウンで列を移動（F5） | 移動先の列の末尾 |
| ドラッグ&ドロップ（F6・F7） | ドロップした位置 |

### 3.7 エラー時の動き

| 場面 | 動き |
|---|---|
| 入力チェックに合わない | 該当する入力欄の近くにメッセージを表示し、保存しない。モーダルは開いたまま |
| 作成・編集・削除に失敗した | 画面上部にメッセージを表示する。モーダルは閉じずに入力内容を残す |
| ドラッグ&ドロップ・並べ替えの保存に失敗した | 画面上部にメッセージを表示し、カードを操作前の位置に戻す |
| ボード画面の読み込みに失敗した | 画面上部にメッセージを表示する |

### 3.8 メッセージ一覧

| # | 場面 | メッセージ |
|---|---|---|
| M1 | タイトルが空（空白だけを含む） | タイトルを入力してください |
| M2 | タイトルが51文字以上 | タイトルは50文字以内で入力してください |
| M3 | 説明が1001文字以上 | 説明は1000文字以内で入力してください |
| M4 | 期限が今日より前 | 期限には今日以降の日付を入力してください |
| M5 | 作成・編集・移動・削除・並べ替えに失敗 | 操作に失敗しました。もう一度お試しください |
| M6 | ボード画面の読み込みに失敗 | カードを読み込めませんでした。ページを再読み込みしてください |
| M7 | 削除確認（S4） | 本当に削除しますか？ |

## 4. 非機能要件

| # | 項目 | 内容 |
|---|---|---|
| N1 | 利用端末 | PCのブラウザ（画面幅1280px程度以上） |
| N2 | 対応ブラウザ | Google Chromeの最新版 |
| N3 | 表示言語 | 日本語のみ |
| N4 | データの保存 | ブラウザを閉じても、PCを再起動しても、カードが消えずに残る |
| N5 | 扱うデータ量 | カードは合計100枚程度まで快適に動く |
| N6 | 操作の反応 | 作成・編集・移動の結果が1秒以内に画面に反映される |
| N7 | 誤操作の防止 | 削除の前に確認ダイアログを表示する |
| N8 | 入力チェック | 3.2のルールに合わない入力は、エラーメッセージ（3.8）を表示して保存しない |

## 5. 画面一覧・画面遷移

### 5.1 画面一覧

| # | 画面 | 種類 | 内容 | 関係する機能 |
|---|---|---|---|---|
| S1 | ボード画面 | ページ | 3つの列とカードを表示。列ごとに「＋カード追加」「並べ替え」ボタン | F1, F6〜F10 |
| S2 | カード作成 | モーダル | タイトル・説明・期限・優先度を入力して作成。押した列がステータスになる | F2 |
| S3 | カード詳細・編集 | モーダル | S2と同じ入力欄＋ステータスのプルダウン＋削除ボタン | F3, F4, F5 |
| S4 | 削除確認 | ダイアログ | 「本当に削除しますか？」 | F4, N7 |

### 5.2 画面遷移

```
S1 ボード画面
 ├─「＋カード追加」を押す → S2 カード作成
 │    ├─ 保存 → S1
 │    └─ キャンセル → S1
 └─ カードをクリック → S3 カード詳細・編集
      ├─ 保存 → S1
      ├─ 閉じる → S1
      └─ 削除ボタン → S4 削除確認
           ├─ はい → S1
           └─ いいえ → S3
```

S2・S3で「キャンセル」「閉じる」を押したときは、入力中の内容を確認なしで破棄して閉じる。

## 6. データ（概念レベル）

ボードは1つ、リストは3つで固定のため、保存するのはカードのみとする。

### カード

| 項目 | 説明 |
|---|---|
| ID | カードを見分ける番号（自動で付与） |
| タイトル | 3.2のルールに従う |
| 説明 | 3.2のルールに従う |
| 期限 | 3.2のルールに従う |
| 優先度 | 3.2のルールに従う |
| ステータス | どのリストに属するかを表す |
| 並び順 | 列の中で何番目か（F7・F9で使う） |
| 作成日時 | 自動で記録 |
| 更新日時 | 自動で記録。内容（タイトル・説明・期限・優先度）の編集と、列の移動（ステータスの変更）のときに更新する。列の中の並び順だけが変わったとき（F7・F9）は更新しない |

## 7. スコープ

### 7.1 作るもの

- 画面：S1〜S4
- 機能：F1〜F10
- 非機能：N1〜N8

### 7.2 作らないもの

| 機能 | 理由 |
|---|---|
| ログイン・ユーザー登録 | 個人用のため |
| ボードの複数化 | ボードは1つで足りるため |
| リストの追加・削除・名前変更 | 3列固定にしたため |
| スマホ対応 | PCのブラウザのみにしたため |
| ラベル（タグ）機能 | 多対多の関係が必要になり、学習の範囲を超えるため |
| 検索・絞り込み | 個人用で100枚程度なら一覧で十分なため |
| コメント・添付ファイル・チェックリスト | タスク管理の最小構成には不要なため |
| 通知 | 期限切れ表示（F8）で代わりになるため |
| アーカイブ | 削除（F4）で足りるため |

### 7.3 将来追加する場合の候補

1. リストの自由な追加（リストを保存し、カードはリストのIDを持つ）
2. ボードの複数化
3. ログイン
4. ラベル機能
